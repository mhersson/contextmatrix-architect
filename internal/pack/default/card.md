## Context

Why this card exists, written so an agent with only this repository
understands it. For a bug: the root-cause hypothesis and its evidence.

## Where

The files, functions and types in this repository the change touches,
verified at the recorded commit, and the files it creates, named as new. For a wiring change, every call site.

## Solution

The decided approach. Every decision is made; never "A or B". Binding
constraints are restated under Acceptance criteria, because nothing else
reaches the reviewer.

## Acceptance criteria

1. Numbered. Each one is a test or a command that can be checked in the
   working tree of this repository.

## Tests expected

The test cases to write, by name and behaviour. For a project the task
names as POC, the main behaviour and what the criteria demand only.

## Out of scope

Explicit non-goals, so the agent does not widen the card.
